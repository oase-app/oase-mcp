# Security Policy

This project is a **cryptographic and authentication client**: it handles an
Oase login identity, refresh tokens, and message encryption keys. Please
treat security issues with care.

## Reporting a vulnerability

**Report privately — do not open a public GitHub issue** for anything
security-sensitive (a vulnerability, a key/token exposure, an auth bypass, a
weakness in how encryption or credentials are handled).

Email **security@oase.app** with:

- a description of the issue and where it is (file / function, if known),
- steps to reproduce or a proof of concept,
- the potential impact as you see it.

We'll acknowledge your report and work with you on it. Please give us a
reasonable chance to address the issue before disclosing it publicly.

## Scope note

This is experimental software provided as-is (see [SUPPORT.md](SUPPORT.md)).
There is no formal bug-bounty program, but responsible private disclosure is
genuinely appreciated.
