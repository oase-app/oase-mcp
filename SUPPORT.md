# Support

**Documentation:** https://dev.oase.app/mcp/

This project is **experimental and provided as-is**. Issues are enabled and
you're welcome to open one — bug reports and questions help — but please set
your expectations accordingly:

- There is **no guaranteed response time** and **no support commitment**.
- It builds on Oase's internal API, which can change without notice, so
  things may break, change, or be discontinued at any time.
- Issues may go unanswered, and a report is not a promise of a fix.

For anything **security-sensitive** (a vulnerability, a key/token exposure,
an auth weakness), **do not** open a public issue — follow
[SECURITY.md](SECURITY.md) and email security@oase.app instead.

If you need a supported integration path, use the identity & SCIM integration:
https://dev.oase.app/identity/
